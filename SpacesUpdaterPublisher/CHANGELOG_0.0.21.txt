Spaces 0.0.21

SPACE SETTINGS
- Rebuilt Space identity/media settings into a compact container.
- Removed the oversized grey preview and removed “Live Preview”.
- Space picture is centered and uses consistent cover/center image fitting.
- PFP actions stay together: Choose new, Adjust crop, Reset icon.
- Icon-frame controls live directly beneath the PFP actions.
- Founder-only Space banner remains compact and backend-enforced.
- Responsive desktop/tablet/phone layout included.

SUPPORT CONSOLE
- Added Account Lookup for Founder, Staff and Support.
- Search by generated Spaces ID (#00100), username or display name.
- Lookup results include Support DM, copy ID, ban/unban and platform-role state.
- Added private Staff Chat for Founder, Staff and Support only.
- Staff chat is stored in D1 and refreshes while open.
- Existing reports, Space restriction/deletion, bans and Support DMs remain available.

DEVELOPER MODE + USER IDS
- Added an Appearance > Developer mode toggle.
- Founder is reserved as public Spaces ID #00001.
- Existing non-Founder accounts are backfilled beginning at #00100.
- New accounts receive the next generated 5-digit ID atomically.
- Internal UUIDs remain unchanged; the generated ID is an additional human-friendly support identifier.
- Developer mode surfaces IDs on profile/member UI and makes them easy to copy.

INVITES + TYPOGRAPHY
- Invite codes are always generated by Spaces; custom invite codes are rejected by the Worker.
- Invite UI explicitly says codes are generated automatically.
- Conversation/Notes category labels are forced to the normal app/system font with ligatures disabled to remove stray V/E glyph styling.
