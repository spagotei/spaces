Spaces 0.0.18 — UI Motion + Space Identity Polish

- Fixed People layout so the first member appears directly below the People search instead of being pushed far down the page.
- Added subtle independent floating motion to member avatars, names and chevrons while keeping every member bubble anchored in its grid position.
- Added richer hover/glow/sheen interactions to People bubbles.
- Rebuilt Space picture editing into its own dedicated Space Identity section with a centered large preview, upload/change/remove controls and icon-frame choices.
- Removed the Space picture tile from the background preset grid. Appearance now contains only backgrounds.
- Simplified the Space profile area into a banner/profile preview so the icon is not duplicated in awkward positions.
- Clicking the active Space header now opens the Spaces-native Space actions menu, including settings/tools where permitted.
- Right-clicking the active Space header uses the Spaces menu instead of the browser/WebView image menu.
- Suppressed the native browser/WebView right-click menu inside the app so Save image / Copy image / Inspect no longer appears from normal app surfaces.
- Added restrained section entrance motion, background-card sheen, icon float, and micro-interactions across navigation controls.
- Added reduced-motion fallbacks.
- No backend or D1 migration required for 0.0.18.
- Version updater now synchronizes package.json, package-lock.json, tauri.conf.json, Cargo.toml and the spaces-app entry in Cargo.lock.
