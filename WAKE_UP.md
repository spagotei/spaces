# Spaces 0.0.3

Quick start:

```powershell
npm.cmd install
npm.cmd run typecheck
npm.cmd run dev
```

Simulator inside VS Code:

`http://127.0.0.1:5173/?lab=1`

Real desktop window after Tauri prerequisites:

```powershell
npm.cmd run desktop
```

0.0.3 also includes a one-time backend `0011_profile_customization.sql` migration + updated Worker for profile banners/accents. See `README_FIRST.md` before using the new profile upload screen against production.
