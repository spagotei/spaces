Spaces 0.0.15 — UI POLISH & PEOPLE
==================================

PROFILE / PRESENCE
- Bottom-left account popover now closes by clicking anywhere outside it.
- Removed the redundant X from that popover.
- Escape also closes the account popover.
- Presence changes update immediately in the account dock.
- Idle now uses a real crescent indicator instead of a broken/unchanged dot.

PEOPLE
- Rebuilt People as compact member bubbles: PFP, name, role, and presence.
- Right-side People rail uses the same rounded bubble language.
- Clicking a person opens a smooth right-side profile drawer instead of a centered modal.
- The drawer shows profile, presence, roles, role assignment controls, recent contributions, report/remove actions, and messaging placeholder.
- Drawer closes by clicking outside or pressing Escape.

MOTION / RESPONSIVE
- Added a keyed page transition layer so switching pages/channels feels intentional.
- Added spring/tween feedback to buttons, People bubbles, profiles, and role controls.
- Improved medium-window constraints so content wins before rails become cramped.
- Channel navigation becomes an overlay sooner on narrow desktop windows.
- Profile drawer adapts to a mobile sheet on small screens.

BACKGROUNDS
- Removed the global wire-grid overlay.
- Legacy Violet Grid now renders as a soft aurora instead of a grid.
- Replaced Violet Grid with Aurora while keeping old saved Spaces compatible.
- Added Velvet, Blue Hour, and Noir Bloom backgrounds.
- The three new background names require the included Worker update, but no D1 migration.
